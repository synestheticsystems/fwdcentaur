# Agent-native task trackers and orchestration: landscape as of September 2026

Research note, 2026-09-24. Compiled by a research agent; every post-2025 claim was checked against a fetched page; where a fetch failed or only secondary sources exist the note says so. Star counts are as displayed on the fetched page that week.

## 1. Beads (`bd`)

**What it is.** Yegge's "distributed graph issue tracker for AI agents, powered by Dolt", released Oct 13 2025, moved from `steveyegge/beads` to the `gastownhall` org; 27.4k stars. v1.0 (April 2026) switched storage to Dolt; v1.3.0 shipped 2026-09-15 and the release notes call it "the first tested release off main since the 1.1 line" (v1.2.1 was retracted, v1.2.2 re-shipped the 1.1.2 tree).

**Data model.** `--type bug|feature|task|epic|chore|decision` plus Gas Town-specific types `merge-request, molecule, gate, convoy`; custom types via config. Dependency types: `blocks|tracks|related|parent-child|discovered-from|until|caused-by|validates|relates-to|supersedes` (default `blocks`); README also lists `duplicates` and `replies-to` (message threading). Statuses `open, in_progress, blocked, deferred, closed`; priority P0–P4. IDs are hash-based (`bd-a1b2`) explicitly to "prevent merge collisions in multi-agent/multi-branch workflows", with dotted hierarchy (`bd-a3f8.1.1`). A `message` issue type gives threads, ephemeral lifecycle and "mail delegation".

**Storage and sync.** Dolt is now the only backend ("SQLite, PostgreSQL and MySQL are gone"; SQLite "removed during the open-core split"). Embedded mode keeps data in `.beads/embeddeddolt/` with a single writer; server mode uses `dolt sql-server`. `.beads/issues.jsonl` is "an export for viewers and interchange, not the source of truth or a backup." Sync is `bd dolt push/pull` against `refs/dolt/data` on the git remote; v1.3.0 adds `bd sync` with exit codes (0 synced, 2 conflict, 3 push-race exhausted). The old JSONL+SQLite design was, per DoltHub (Mar 13 2026), "too fragile to be workable" (last-write-wins, unreliable sync, no audit of why state changed); it capped out around 4 concurrent agents versus ~160 on one host / ~600 on k8s with Dolt. Yegge himself called the JSONL design "a crummy architecture (by pre-AI standards) that requires AI in order to work around all its edge cases" (quoted by Ian Bull, Jan 24 2026), citing JSONL merge conflicts, manual handoffs, sync-branch setup overhead, and "context rot" where agents forget Beads mid-session despite hooks.

**Ready work, leases, memory.** `bd ready` = open with no active blockers; dependency-blocked issues keep status `open` but are hidden (`bd blocked`). `bd update --claim` is atomic; v1.3.0 adds work leases (`bd heartbeat/reclaim/unclaim`, 5-minute TTL). Memory: "semantic 'memory decay' summarizes old closed tasks", `bd remember`, and `bd prime` injects context; Cursor/Claude hooks re-inject after compaction. Release notes admit silent failures: expired defers left "241 beads, including P1s, silently dark"; `--label-any` was dropped on `bd ready --claim` so workers claimed outside their lanes.

**Agent interface.** CLI with `--json` everywhere is primary. The beads-mcp README: "For environments with shell access (Claude Code, Cursor, Windsurf), the CLI + hooks approach is recommended over MCP" (~1–2k tokens vs 10–50k for MCP schemas); MCP is for "MCP-only environments like Claude Desktop". v1.3.0 adds `bd serve` (41 OpenAPI operations), a public Go API, and an opt-in append-only events journal.

**Human UI.** None first-party. Community: `beads_viewer` (`bv`, TUI with DAG, PageRank, critical path), three VS Code extensions (`beads-ui`, `planet57.vscode-beads`, `4UtopiaInc`), a web kanban.

**License/business.** MIT. No acquisition found. "Beads Village" is not Yegge's: it is a third-party MCP wrapper combining Beads with Agent Mail (LobeHub listing). Gas City is a company (CEO Chris Sells; built by Julian Knutsen and Sells) per secondary sources only; Yegge wrote "I did not write Gas City" (Apr 24 2026). Kilo (itself acquired by Anaconda, per Kilo's banner) sells hosted Gas Town, GA May 19 2026 (rywalker.com). The "open-core split" phrase in v1.3.0 notes implies a commercial edition; no pricing found.

Sources: github.com/gastownhall/beads README and docs/CLI_REFERENCE.md (Sept 2026); releases/tag/v1.3.0 (2026-09-15); dolthub.com/blog/2026-03-13-multi-agent-persistence; ianbull.com/posts/beads (2026-01-24); integrations/beads-mcp/README.md.

## 2. Gas Town

Yegge's orchestrator, open-sourced Jan 1 2026; v1.0 Apr 3, v1.2.1 Jun 6; 15.9k stars (June); MIT; requires tmux 3.0+, Claude Code, Go, Beads, Dolt. Roles (README): Mayor (coordinator), Polecats ("worker agents with persistent identity but ephemeral sessions"), Witness (per-rig health monitor), Deacon (background patrol), Refinery (per-rig Bors-style bisecting merge queue), Crew (your workspace), Dogs (infra workers), Overseer (human, escalation target with own inbox). Mail: `gt mail send`, `gt mail inbox`, `gt nudge`; mail is delivered by injecting into agent hooks (Claude via `.claude/settings.json`). Handoff: `gt sling <bead> <rig>` pins work to an agent's "hook" (GUPP: "If there is work on your hook, YOU MUST RUN IT"); molecules are bead-chain workflows resumable from the last unclosed step; convoys bundle beads; `gt done` feeds the Refinery; `gt handoff` restarts a session when context fills.

Criticisms (all dated): DoltHub (Jan 15 2026): ~$100 for 60 minutes, "about 10X the cost of a normal Claude Code session", Mayor reported all bugs fixed with two PRs, a PR merged despite failing tests. Tenzin Wangdhen (Feb 19 2026): mail and daemons needed manual patching, 141 orphaned Claude processes, tmux mastery required, poor observability, "throughput over correctness", demands yolo-mode. Augusteo (Apr 2026): early Deacon "serial killer sprees" killing workers mid-job; fake tmux input needed to overcome model politeness. de hÓra (Feb 28): Dolt is a single point of failure ("If you can't create beads, the system stops"); Claude-specific in practice. Then Yegge, Aug 2026 ("The Shape of Things to Come", via Simon Willison Aug 4): "Gas Town effectively burned down... 4.7 was the final straw" (Opus 4.7's "just two more things" tic); it "was intended to be reusable, but I only ever wound up using it to build itself." He now runs a closed-source bespoke harness (Wheelhouse) that still uses "a Beads work-graph for the structure". Gas City (Apr 2026) rewrites Gas Town as an SDK with "zero roles" hardcoded and formulas run "as a graph across many agents". The Wasteland (Mar 2026, federated work-trading network) is secondary-source only.

## 3. Vibe Kanban (BloopAI)

Kanban issues that spawn coding agents (Claude Code, Codex, Gemini CLI, Copilot, Amp, Cursor, OpenCode, Droid, Qwen) in git-worktree workspaces with branch, terminal, dev server, inline-commented diff review sent back to the agent, built-in browser, PR creation; Rust backend, SQLite, MCP server, Docker self-host; Apache-2.0; 28.2k stars. Bloop shut down Apr 10 2026: "the vast majority are free users and we couldn't find a business model that we could get excited about" despite "thousands of software engineers" daily. Remote services (kanban issues, comments, projects, organizations) were removed after 30 days; the project is now community-maintained and fully local. Lesson: the collaborative/remote layer was the paid part and the first thing cut.

Source: vibekanban.com/blog/shutdown (2026-04-10); github.com/BloopAI/vibe-kanban.

## 4. Paperclip

Verified. Paperclip Labs, Inc.; launched Mar 2 2026 by pseudonymous "@dotta"; MIT; 82.6k stars; v2026.916.1 (Sept 21 2026). Node server + React; embedded Postgres locally, bring-your-own Postgres in prod; cloud deployment mentioned, no pricing found. Agents are employees in an org chart with roles, reporting lines, budgets; they run via adapters (Claude Code, Codex, Cursor, Gemini, OpenClaw, bash, HTTP webhooks: "If it can receive a heartbeat, it's hired"). Tickets carry company/project/goal/parent links, "atomic checkout with execution locks, first-class blocker dependencies", and an inbox state; full tool-call tracing in an append-only log; MCP gateway on the roadmap. Web dashboard, mobile-ready. Framed as business automation, not code review: no code-line anchoring.

## 5. OpenAI Symphony

Verified: Apr 28 2026; a spec plus an "experimental" Elixir reference implementation; Apache-2.0; 27.4k stars; self-described "low-key engineering preview for testing in trusted environments". SPEC.md abstracts the tracker behind an adapter that normalizes provider items into an `Issue`; provider-native states (Todo/In Progress/In Review/Done are illustrative) plus orchestrator claim states (Unclaimed, Claimed, Running, RetryQueued, Released); runs end at a handoff state such as "Human Review". Per-issue workspace directories; VCS behavior is implementation-defined via hooks; `max_concurrent_agents` default 10; exponential retry backoff; a repo-owned `WORKFLOW.md` (YAML front matter + prompt template, hot-reloaded). The reference implementation supports Linear only; no Beads adapter was found, so a "Linear/Beads" premise is unverified and probably wrong. Context: Linear's CEO declared "Issue Tracking is Dead" (Mar 24–26 2026) and pivoted to agents/skills (Business plan $16/user/mo).

## 6. Other task managers

- **Backlog.md** (MrLesk): MIT, 6.8k stars. Plain `.md` task files in `backlog/` (`TASK-1`, acceptance criteria, milestones, dependencies, comments); CLI + MCP; TUI kanban and web board; explicitly "human-first", three review checkpoints (spec, plan, code). No atomic claims.
- **claude-task-master** (eyaltoledano/Hamster): 28.1k stars; MIT + Commons Clause; `tasks.json` with subtasks, dependencies, tags; MCP is the recommended interface (36 tools ≈ 21k tokens, with reduced "standard"/"core" modes) plus CLI; PRD-to-tasks. Commercial arm Hamster: free 10 briefs/month, Team $40/creator/month, cloud agent opens PRs (pricing from a search summary of tryhamster.com; not fetched directly).
- **Claude Code Tasks** (v2.1.16, Jan 2026): `~/.claude/tasks/<id>/`, blocking deps, shared across terminals via `CLAUDE_CODE_TASK_LIST_ID`; no repo awareness.
- **Claude Code Agent Teams** (experimental, `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`): shared task list (pending/in progress/completed, deps block claiming, file-lock claims), per-agent mailbox JSON at `~/.claude/teams/{team}/inboxes/{agent}.json`, `SendMessage`, hooks `TeammateIdle/TaskCreated/TaskCompleted`. Limits: one team per session, no resume of in-process teammates, "task status can lag", tokens scale linearly. Local, session-scoped, not in-repo.
- **Shrimp Task Manager**: MCP-only, MIT, dependency tracking, optional web GUI; community-maintained.
- **Archon** (coleam00): the task-management/RAG product is archived; the repo is now a YAML workflow engine.
- **swarm-tools** (Joel Hooks): MIT, 742 stars; git-backed `.hive/` cells plus "Swarm Mail" (DurableMailbox, DurableLock file reservations, DurableDeferred checkpoints); OpenCode-first.
- **MCP Agent Mail** (Dicklesworthstone): 2.2k stars; markdown messages in a per-project git repo + SQLite FTS; `agents/{name}/inbox|outbox/`; advisory file leases; web UI with "Human Overseer" directives; recommends Beads for status and sharing `bd-123` as `thread_id`.

## 7. Entire

Verified: Thomas Dohmke (ex-GitHub CEO), announced Feb 10 2026 with a $60M seed at $300M valuation (Felicis lead; Madrona, M12, Basis Set, 20VC, others). Checkpoints (MIT CLI) hooks git and stores each agent session as a git ref `refs/entire/checkpoints/<shard>/<id>` (transcript, prompts, files touched, tokens, tool calls, subagent task records, best-effort secret redaction); agents: Claude Code, Codex, Copilot CLI, Cursor, Antigravity, Droid, OpenCode, Pi. Web product shows commit pages with sessions/steps/tokens (dispatch 0x0019). Stated roadmap: git-compatible database, "semantic reasoning layer"/context graph, AI-native SDLC UI, "later in 2026"; pricing planned as seat + consumption + free tier after preview (The New Stack), not live. No task graph, annotations, or inbox exist today.

## 8. Parallel-worktree apps

- **Conductor**: YC S24, $22M Series A (Spark, Matrix), ~6 people; Mac-only, proprietary, free; Claude Code/Codex/Cursor/OpenCode in worktrees with diff review, PRs; "Dispatcher" (v0.63, June 2026); paid collaboration tier and Jira integration planned, unshipped; criticized for no sandboxing.
- **Claude Squad**: AGPL-3.0 TUI over tmux + worktrees, 8.5k stars; no task integration.
- **Superset**: Elastic License 2.0 (source-available), macOS + Linux; free, Pro $15/user/month (dev.to, Jul 22 2026); CLI, TS SDK, MCP server, remote hosts, scheduled "automations".
- **Emdash**: YC W26, Apache-2.0, 5.8k stars, cross-platform; pulls tickets from Linear, GitHub, Jira, GitLab, Asana and more; SQLite local.
- **Nimbalyst** (Crystal, renamed Feb 2026): MIT, cross-platform + iOS; session kanban, tasks, docs/diagrams.
- **Xum** (Coder's Mux, renamed after a trademark claim): AGPL-3.0, 2k stars; local/worktree/SSH isolation, VS Code extension.

## 9. Spec-driven tools

Pricing (third-party page rechecked Sept 14 2026): Free 50 credits, Pro $20/1000, Pro+ $40/2000, Pro Max $100/5000, Power $200/10000, $0.04/credit overage; kiro.dev/pricing not fetched directly. ## 10. Direct competitors to the whole vision

Nothing combines a dependency graph, line-anchored annotations, and agent inboxes. Closest partials:
- **Anchored Comments** (VS Code, jonathan-lee, v1.2.0, Aug 23 2026, 8 installs): threads anchored by git blob baseline + Myers diff + fuzzy fallback, stored as append-only `.comments/threads/<id>.jsonl`, bundled MCP (`list_threads/reply_to_thread/resolve_thread`), assign-to-agent, claims/leases, blocking severity, commit provenance "notary". No task graph. kongdd/code-annotate (`.annotations.json`, 0 stars) is a simpler variant.
- **Google Antigravity**: Agent Manager has an Inbox; Google-Docs-style comments on task lists, implementation plans, walkthroughs, and "inline comments" on proposed changes; no dependency graph; proprietary.
- **Paperclip** and **Claude Code Agent Teams**: deps + inbox, no code anchors.
- **Beads + Gas Town / Agent Mail / swarm-tools**: graph + mail, no editor surface.
- **Vibe Kanban / Conductor / Superset**: inline diff comments sent to the agent, no graph.
- **GitHub Agent HQ mission control** (Dec 1 2025): assign and steer Copilot tasks across repos; PR-centric.

## Cross-cutting lessons

1. **Git-as-database failed for structured concurrent state.** Beads abandoned JSONL+SQLite for Dolt; Vibe Kanban's server-side issues/comments were the part that died. What survives in-repo: append-only event logs with hash IDs (Anchored Comments, Beads events journal, Agent Mail markdown), or a real merge-capable database (Dolt, with its single-writer embedded mode).
2. **CLI + hooks beat MCP for shell-capable agents** (Beads: 1–2k vs 10–50k tokens; Task Master ships reduced MCP modes for the same reason); MCP is for MCP-only hosts; an HTTP API is what UIs actually consume.
3. **"Ready" = open and no active blockers is universal**, but claims need leases with TTL, heartbeats and atomic checkout (Beads v1.3.0, Paperclip, Agent Teams). Silent failure modes are the recurring bug class: dark deferred items, dropped filters, lagging task status.
4. **Inboxes are everywhere but disconnected from code.** Every system reinvents mail (`gt mail`, Agent Mail, Swarm Mail, `inboxes/*.json`, Paperclip, Antigravity) and delivers it by injecting into context at session start or by nudging; reliability of delivery and of agents acting on it is the chronic complaint. None anchors a message to a line or links it into a dependency graph.
5. **Context rot is real**: agents forget the tracker mid-session; Beads answers with hooks that re-inject after compaction and `bd prime`.
6. **Heavy orchestration burned its own author.** Gas Town's cost, yolo-mode, and observability problems ended with Yegge declaring it dead in August 2026 while still keeping the Beads work-graph; Gas City reacts by making roles configuration. A supervising/triage agent (Mayor/Witness/Deacon analogue) must be cheap, observable, and not mandatory.
7. **Money is the open problem**: bloop died on free users; Conductor is free with unshipped paid tiers; Beads went open-core with a hosting partner; Entire raised $60M on a platform promise.
8. **Gaps fwdcentaur would fill**: line-anchored annotations that become graph nodes; first-class "why" (only Paperclip's goal links and Backlog.md's spec prose approximate it); a per-person/agent "scope" object visible to humans (Gas Town hooks and Symphony workspaces are agent-only); a repo-persistent graph shared across vendors (Anthropic's Tasks/Teams are session-local and Claude-only); and an IDE-native graph view (Beads has only community VS Code extensions; Kiro's waves are locked to its IDE).
